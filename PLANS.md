# 이어짐 execution plan

## Approved runtime contract

The product is a source-change workspace, not an arbitrary code generator. Korean pasted text and a purpose produce four editable block types. New source text produces an evidence-linked proposal; user approval applies the complete valid bundle. Preserve manual edits, completion, locks and stable identity. Main scenario: four travelers share a fixed KRW 900,000 cost (225,000 each), then three travelers share it (300,000 each), arrival changes from 10:00 to 16:00, and a locked second-day 19:00 dinner survives or produces an explicit conflict. A second assignment-deadline scenario must use the same engine.

Constraints: 6 hours/day user availability; TypeScript application; React/Vite, Hono, Workers, D1, one Queue; USD 30 approved overall service budget through the voting period. Seven-day inactivity retention, anonymous same-browser ownership, manual deletion. No arbitrary code/SQL, runtime MCP, real bookings/messages, file ingestion, or collaborative editing. The coding model and service model are separate.

Sources remain immutable; source relation (addition/correction/replacement) is explicit. Source catalog revision and workspace content revision are distinct. AI proposals are schema- and reference-validated. Deterministic calculations and protections are owned by the core engine. DB application uses compare-and-swap plus an atomic transaction. Content restoration creates a new revision and cannot restore ledgers, owner state, source catalog, or expiry.

Runs reserve an admission budget before dispatch; this is not a provider invoice hard cap. Queue delivery is at-least-once; a database claim prevents duplicate paid calls. Persist pending dispatch before sending, recover unsent jobs, and do not automatically repeat calls with uncertain outcomes. The current user-approved runtime model is gemini-3.8-flash on native generateContent, store:false, no automatic retries, a 60-second timeout, low thinking and 4096 candidate output tokens. The 24360 microUSD reservation includes 12000 input tokens at Standard pricing through 2026-12-31. Combined thinking/output billing can exceed the admission assumption: retain measured usage even on failed output, and persist a global over-reserve policy violation to block subsequent live calls pending operator review. Limit each source to 6000 characters and combined sources to 24000; additionally enforce the assembled model input budget. Synthetic fixtures are labeled and must never masquerade as live AI processing.
