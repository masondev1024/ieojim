## 실험 계약과 재현

- 모델: `gemini-3.8-flash`, contract v2, 두 전략 모두 full context.
- 기존 acceptance 12개를 변경하지 않고 전략별 1회씩 총 24회 호출했다. 전체 코퍼스 해시: `af23574ed7580c1758c3853a5abe3a2d3581f79931540feb8ebbeaa9c6855e88`.
- 실행 전 모델·문맥·정책·계약·엔진·정답·채점 파일 8개를 동결하고 실행 후 SHA-256 일치를 확인했다. 사례별 context 해시, 공유 schema/config/model-policy 해시가 일치한다. 전략 지시문은 의도적으로 다르며 각 전략 내에서 고정됐다.
- 12회씩 두 묶음으로 실행했다. 묶음당 예약 $0.292320, 총 예약 $0.584640. 관측된 총 토큰 비용 추정은 **$0.125791**이다. 로컬 CLI 평가이므로 공개 서비스 D1 예약 횟수는 사용하지 않았다. 평가 비용도 프로젝트 총 예산에 포함한다.
- 자동 재시도 없음. 실패 출력도 보존하는 실행기로 돌렸으며 이번 24회에는 실행·평가 실패가 없었다. 집계 결과 `comparable=true`, 누락·중복·provenance mismatch 모두 0.

추가 유료 호출 없이 계획과 기존 결과를 읽는 명령:

```sh
npm run eval:live -- --suite acceptance --finals-paired-plan
npx tsx scripts/eval-live.ts --aggregate artifacts/eval-2026-09-12T07-45-04.755Z-61df61ec-21f4-47f1-8d1a-886588497ade.json --aggregate artifacts/eval-2026-09-12T07-46-28.337Z-689e8925-6c62-44dc-9872-6b0b849eb147.json
```

실행 계획, 동결 해시, 원본 경로와 안전한 집계는 `artifacts/finals-delivery-2026-09-12/`의 `paired-plan.json`, `evaluation-freeze.json`, `paired-results.json`, `paired-summary.json`에 있다. `artifacts/`는 Git에서 제외되어 있으며 공개 제출물로 자동 게시하지 않는다.

## 해석의 한계

12개 합성 사례이며 각 조건을 한 번만 실행했다. 전략별 순차 묶음이라 제공자 부하·시간 순서 효과를 통제하지 않았다. 모델 호출 지연은 사람의 검토 시간이나 Queue·브라우저를 포함한 서비스 전체 지연이 아니다. 비용은 응답 토큰과 모델 정책 가격으로 계산한 추정이며 공급자 청구서나 인프라 비용이 아니다.

두 전략 모두 동일한 `buildChangeSet` 보호 엔진을 거친다. 따라서 정확도 우위, 일반 입력 정확도 100%, 경쟁 제품 대비 비용·시간 절감, 시장 검증으로 확장해 주장하지 않는다. 이전 실패 사례와 과거 평가 보고서도 그대로 보존한다. 실제 사용자 시험은 사용자의 결정에 따라 추후 진행한다.
