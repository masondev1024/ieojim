# 이어짐 — 대회 제출용 범용 제품 방향

2026-09-14 사용자 수정 요청: 기업 비서로 좁힌 범위를 넓혀 AI Championship 출품 목적에 맞춘다.

## 제품과 대상

**새 안내에 맞춰 일정·비용·준비할 일을 갱신하면서, 내가 정한 결정을 지켜주는 AI 워크스페이스.**

사용자는 외부 안내·요청을 받아 계획과 준비 목록을 만들고, 정정이 올 때마다 다시 맞춰야 하는 사람이다. 직장인·프리랜서·학생·생활 일정을 챙기는 개인이 후보이며, 이들 모두의 반복 수요가 검증됐다는 뜻은 아니다. 기업 비서·경영지원은 활용 사례 중 하나이자 후속 상용화 가설로 둔다.

최근 구현한 준비 마감·예상 시간·검토 확인은 모든 작업 공간의 체크리스트에서 사용할 수 있다. `src/core/contracts.ts:37`, `src/client/workspace/WorkspaceApp.tsx:958`. 네 블록과 단일 변경·승인 엔진을 계속 사용한다. 사용자층을 넓힌다는 이유로 직군마다 별도 데이터 모델이나 외부 실행 기능을 추가하지 않는다.

## 대회에 맞는 이유

공식 예선 기준은 기획력·실현 가능성·확장성·AI 활용 적절성, 본선은 기획력·확장성·기술력·발표 전달력이다. 범용 서비스에 별도 가점을 준다는 규정은 없다. 같은 엔진이 세 종류의 실제 흐름을 처리하는 모습을 보여 주는 것이 우리의 확장성을 구체화한다는 판단이다. [공식 안내·심사 FAQ](https://static.wanted.co.kr/ai-championship/2026/landing.html)

## 세 용례와 현재 증거

| 맥락 | 변경 문제 | 현재 증거 |
|---|---|---|
| 업무·프로젝트 | 미팅 시간·장소·자료 마감 변경 | coordination 로컬 구현과 브라우저 검사 완료. 기업 전용 권한·초대 연동 없음. |
| 학업·과제 | 과제 마감·제출 준비 안내 변경 | syllabus 예시가 동일 엔진을 사용함. 조직 학사 시스템·공동 편집 없음. |
| 생활·약속 | 여행 인원·도착 시간·분담 비용 변경 | departure 복합 예시 공개 배포 기록 있음. 예약 자동 변경 없음. |

면접·이사·가족 행사·병원/학교 내부 행정은 추가 입력 평가 후보다. 현재 검증된 전용 서비스로 소개하지 않는다.

## 제출 메시지와 시연

제목 제안: **이어짐 — 새 안내를 반영해도, 내 결정은 이어집니다**

문제 한 줄: **새 안내가 올 때마다 일정·비용·준비 목록을 다시 맞추며 확정한 결정과 완료 기록을 놓치는 문제를 해결합니다.**

핵심 시연은 새 정정이 일정·자료 마감을 바꾸는 동시에 고정한 약속과 완료한 준비를 건드리는 순간이다. 근거·변경 전후·사람의 두 선택·저장 결과를 보여 준다. 대표 예시 하나를 깊게 보여주고 학업·생활에서도 같은 흐름이 동작함을 짧게 증명한다. 현재 공개 자료는 departure이며, 향후 대표 화면을 발표/미팅 준비로 바꿀 경우 먼저 해당 버전을 검증·배포하고 캡처한다.

AI의 역할은 안내문 의미 해석과 근거를 연결한 변경 제안이다. 사용자 고정·완료·수정 상태, 허용 계산, 기준 버전, 저장 권한은 코드가 검증한다. 관계 추출 완전성이나 경쟁 제품 대비 우위를 보장하지 않는다.

## 구현 우선순위

1. 메인 소개와 실제 작성 경로를 범용 문구로 정리하고 업무·학업·생활 세 체험을 제공한다. 기존 경로와 저장 자료는 유지한다.
2. 같은 엔진이 세 맥락에서 승인·저장·재조회까지 동작하는 시연을 정리한다. 합성 체험과 실제 모델 호출 결과를 구분한다.
3. 공개 버전이 갱신된 뒤 제출 문구·16:9 화면·manifest를 맞춘다. Calendar 실행은 직군 공통의 승인·제한된 캘린더·재조회 구조로 후속 개발한다.

현재 입력은 사용자가 제공하는 텍스트이며 자동 메일/메신저 수집, 전역 일정 최적화, 외부 캘린더 쓰기는 구현 범위에 포함되지 않는다. 단일 소유자와 비활동 7일 보존 등 운영 계약도 그대로다.
