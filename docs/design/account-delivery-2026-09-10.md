# A1 계정과 게스트 작업 연결 구현 기록

2026-09-10. 계정 서버·UI·데이터 연결을 구현하고 기존 staging에 배포했다. 실제 Google 계정 인증 왕복은 운영자 OAuth 클라이언트 설정 전이므로 미검증이다. 전체 상용 제품 완성이 아닌 A1 구현/자동 검증 완료 기록이다.

## 구현

- Better Auth 1.7.3의 Google 인증, D1 세션, 고정 7일 세션 만료, 현재/다른 기기 로그아웃.
- `/login`, `/settings`와 작업 화면 계정 상태. 설정이 없으면 사실대로 로그인 비활성을 알리고 게스트 진입 제공.
- 계정과 게스트 자료 목록 확인 후 명시적으로 연결. 정확한 목록/버전을 트랜잭션에서 다시 확인하며 동일 요청은 결과를 재사용.
- 기존 owner를 계정에 연결해 작업·원문·이력·진행 중 실행·비용 장부의 관계 유지. 연결 후 옛 게스트 권한으로 이미 준비된 읽기/쓰기도 DB 실행 시 거부.
- 연결된 모든 owner의 작업 공간/일별 AI 실행을 계정 단위로 합산. 내용 보관은 현재 7일 미사용 기준 유지.
- 인증 메타데이터 입장 제한, 만료 정리, OAuth callback 입장 제한과 오류 주소 정규화. 정책 행이 없으면 새 인증 메타데이터 생성 거부.
- 공급자 작업별 12초 응답 제한. 늦게 돌아온 결과로 사용자/세션을 생성하지 않음. 라이브러리가 AbortSignal을 노출하지 않으므로 상위 HTTP 전송 자체의 취소는 보장하지 않음.
- 로그인/연결/로그아웃 동안 신원 변경 시 개인 화면 상태 비움. 연결 응답 유실 재시도, 미리보기 변경 후 재동의, 성공/실패 안내 유지.

## 검증과 수정

최종 `npm run verify`: 타입/린트/빌드, **201 unit + 137 integration** 통과. `npm run test:e2e`: **47 Chromium** 통과. `npm run test:staging`: **8 Chromium** 통과. 마지막 원격 검사 추가 후 해당 파일 ESLint/전체 TypeScript도 통과했다. `npm audit`: 0건. Worker dry-run: 2690.26 KiB / gzip 460.50 KiB. 선택적으로 로드되는 Three 청크의 Vite 크기 경고는 남아 있다.

실제 D1 회귀는 계정 격리, 취소된 세션/옛 게스트 토큰, 동시 연결/중복 결과, 변경된 미리보기, 한도 경쟁, 진행 중 실행 완료와 장부 보존을 포함한다. 시험용 세션은 격리 D1에 만들었고 Google 요청은 대체/차단했다. 제품에 시험 로그인 API가 없으며 자동 검사는 실제 Google 사용자의 성공을 증명하지 않는다.

검사 과정에서 발견한 실제 문제를 수정했다: Hono wildcard 미들웨어의 workspace ID 접근, 보안 쿠키 삭제 속성, 로컬 프록시 출처, 소비된 요청 본문 재사용, 확인 메시지 초기화, 작업 생성 후 보조 목록 조회가 UI를 잠그는 문제. 기존 회귀의 계정 API 응답/추가 DB 열/권한 확인 batch에 맞춰 시험 장치를 갱신했으며, 경쟁 상황 주입 여부를 명시적으로 검증한다. 최초 실패 로그도 보존한다.

독립 인증/소유권 리뷰는 각 범위에서 APPROVE, 남은 중대 지적 0건이다. 내부 테스트용 소수점 제한 시간 정규화에 대한 선택적 LOW 관찰은 기본 정수 12,000ms 운영 설정에 영향을 주지 않는다.

## 다음 단계와 제출 준비

실제 Google 활성화는 [운영 가이드](../runbooks/accounts.md)의 웹 OAuth 클라이언트/동의 화면 설정과 실제 두 브라우저 왕복 확인이 필요하다. A2 계정 보관 정책·사용량·내보내기·계정 삭제와 B1 결제는 아직 구현 완료로 표시하지 않는다. 외부 사용자 시험과 알림 연결은 사용자 요청대로 보류한다.

사용자가 제공한 제출 폼을 반영한 [제출 준비 초안](../submission/preparation.md)에 대표 이미지부터 500자 본문·실제 도구 선택·서비스 링크·16:9 최대 5장 순서를 기록했다. 최종 구현/제출 빌드를 고정한 뒤 실제 화면을 촬영하고 문구를 확정한다. 현재 제출이나 이미지 업로드를 수행하지 않았다.

정확한 로그와 파일 해시: `.omx/verification-accounts.json`.
