# A2 사용량·현재 데이터 내보내기와 제출 자료

2026-09-10. A1 계정 구현 위에 실제 사용량과 현재 데이터 소유·이동 기능을 더했다. 계정 전체 삭제, 영구 보관, 결제까지 포함하는 전체 상용 로드맵의 완료 기록은 아니다. 실제 Google 로그인 활성화는 운영자 OAuth 설정 전이므로 미검증이다.

## 구현과 이유

- 인증된 사용자는 설정에서 연결한 모든 작업 공간의 사용량, 일일 AI 실행 예약량, UTC 기준 다음 초기화 시각과 작업별 만료 시각을 확인한다. 한 DB 트랜잭션에서 일관된 값을 읽고, 조회만으로 보관 기간을 연장하지 않는다.
- 삭제한 작업의 당일 예약량도 유지해 삭제/재생성으로 한도를 우회하지 못한다. 실시간 모델 청구서 금액을 표시하는 기능은 아니다.
- 게스트와 회원 모두 접근 가능한 작업의 현재 계획·원문을 JSON v1로 내려받는다. ID, 근거 위치, 수동 수정·완료·고정 상태를 보존한다. 현재 메타데이터/원문/스냅샷은 같은 권한 확인 트랜잭션에서 읽는다.
- 형식·근거 일치·크기 검증 후 응답한다. 인증/계정 소유자 식별자, 비용 장부, 공급자 정보, 명령 응답, 검토 중 제안, 과거 스냅샷 본문은 내보내지 않는다. 전체 이력 백업이나 가져오기 기능은 아니다.
- 최종 파일 전체를 2MiB로 제한하며 SHA-256은 `JSON.stringify(content)`의 UTF-8 바이트를 대상으로 한다. 체크섬은 우발적 변경 확인용이지 전자서명이나 신뢰할 수 있는 복원 권한이 아니다. 원문 근거 위치는 JavaScript 문자열의 UTF-16 인덱스다.
- 브라우저는 15초 제한, 스트림 크기 제한, 스키마·작업 ID·체크섬 확인 후에만 파일을 만든다. 화면 이동/해제 시 요청 취소와 Blob URL 정리를 수행한다. 본문 스트림을 안전하게 읽지 못하는 환경은 다운로드를 거부한다.
- 사용량 응답이 실패하거나 형식이 잘못되면 이전 개인 사용량을 비워 다른 신원에 남지 않게 한다. 게스트 설정 화면은 계정 사용량을 요청하지 않는다.

## 검증

`npm run verify`: 타입·린트·빌드, 단위 **201개**, 통합 **156개** 통과. 최종 클라이언트 크기 제한 보완과 원격 테스트 추가 후 타입·린트도 통과했다. `npm run test:e2e`: 로컬 Chromium **53개** 통과.

집중 D1/HTTP 검사 32개는 계정 합산, 삭제 후 사용량 보존, UTC 경계, 취소된 세션, 다른 소유자/만료/삭제된 작업의 다운로드 거부, 원문 근거 손상, 정확히 2MiB와 초과 응답을 포함한다. 첫 실패였던 D1 테스트의 `first(0)` 사용은 명시적인 결과 열 이름으로 바로잡았다. 새 API는 마이그레이션과 모델 호출을 필요로 하지 않는다.

독립 서버/계약 리뷰와 UI 리뷰 모두 요청한 범위에서 APPROVE. UI의 선택적 LOW 중 스트림 없는 응답의 무제한 버퍼 가능성은 거부 처리로 보완했다. 기존 계정 상태 응답의 런타임 스키마 일관성 개선은 선택적 후속 관찰로 남는다.

Staging Chromium **9개** 통과로 단위/통합/로컬/원격 합계 **419개**다. 최종 Worker dry-run은 2699.70 KiB / gzip 462.51 KiB다. 선택적으로 로드되는 Three 청크의 크기 경고는 남아 있다. 의존성 변경은 없고 A1의 취약점 검사 0건 기록을 유지한다.

## 배포

- URL: https://ieojim-staging.masondev1024.workers.dev
- 버전: `84032c03-ef2a-4630-82ed-7de93933b7da` (A2 최초 배포 `7ab06280-825a-4e54-9ea6-2465e09c860b`, 직전 A1 `fa3f43af-e68d-4cbd-9380-be2718abe3c5`).
- A2 추가 마이그레이션 없음. 일반 로컬 DB와 서버는 재설정하지 않았다.
- 공개 계정 응답은 `authAvailable: false`; 모델 설정은 `liveAvailable: true`. 이번 단계에 새 유료 모델 호출은 없었으므로 설정 상태와 실제 새 모델 응답을 구분한다.
- `/THIRD_PARTY_NOTICES.txt`의 배포 내용은 로컬과 해시 일치. 패키지 본문 고지와 SUIT 라이선스를 함께 배포했다.
- Python urllib 공개 접속 확인은 403을 반환했다. 별도 curl 확인과 실제 Chromium 9개는 정상 통과했으며 이 차이를 앱 성공으로 숨기지 않고 가용성 기록에 남겼다.

제출 캡처 검토에서 긴 검토 목록을 따라 스크롤하면 현재 계획이 사라지는 데스크톱 사용성 문제를 확인했다. 1181px 이상에서 검토 패널에 독립 스크롤과 키보드 포커스를 추가하고, 작은 화면은 문서 흐름을 유지했다. Page Down으로 목록을 내려도 현재 도착 일정이 화면에 남는 회귀 검사와 독립 리뷰를 통과했다. 최종 배포본에서 실제 1600×900 PNG 5장을 촬영하고 육안 검토했다. 초기 구도에서 비용 전후/충돌 선택이 잘린 문제와 보호 상태 가독성을 고쳤고, 원격 응답 대기는 staging 검사와 같은 15초로 맞췄다. 앱 상태를 조작하거나 합성 예시 표시를 숨기지 않았다. 최종 캡처는 오류 없이 완료했고 본인이 만든 작업 공간 1개를 삭제했다. 파일과 촬영 기록은 `docs/submission/assets/`에 있으며 최종 로그는 `artifacts/submission-capture-final-accepted.log`다.

제출 가이드는 필수 항목 순서, 243자 AI 본문, 실제 React/Gemini 체크와 Codex 별도 표기, 서비스 URL, 이미지 5장, 직접 체험 및 제출 완료 확인 순서를 담는다. 사이트 폼 제출·업로드는 수행하지 않았다. 정확한 소스/검증 해시는 `.omx/verification-account-data-controls.json`에 기록한다.

## 남은 경계

보관 정책은 계정도 7일 미사용 기준이다. 장기 보관·계정 전체 삭제·판매자/가격/환불/결제 정책은 별도 설계가 필요하다. 실제 Google 왕복은 [계정 운영 가이드](../runbooks/accounts.md)의 운영자 설정과 두 브라우저 확인이 필요하다. 사용자 시험과 외부 알림은 사용자가 보류했다.

제출 가이드는 [폼 입력 순서](../submission/preparation.md)를 따른다. 실제 화면과 합성 예시를 사용하고, 제공되지 않은 사용자 성과나 아직 미검증인 기능을 주장하지 않는다. 대회 사이트의 실제 제출·이미지 업로드는 수행하지 않는다.
